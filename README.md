# Place Recommendation Web App 🌍

A full-stack web application designed to deliver tailored location recommendations through a seamless user interface. This project highlights a balance between robust backend architecture and high-quality digital design, featuring a clean, modern aesthetic with dark-theme elements, glassmorphism, and bold typography.

**[Live Demo](https://place-rec-app-pi.vercel.app)**

## Tech Stack
* **Frontend:** React, JavaScript, HTML/CSS 
* **Backend:** Python, Django REST Framework
* **Deployment:** Vercel

## Key Features
* **RESTful Architecture:** Efficient, scalable data handling between the React client and Django server.
* **Clean UI/UX:** A minimalist, responsive frontend designed for an intuitive user experience.
* **End-to-End Development:** Demonstrates a complete full-stack workflow, combining functional software development logic with strong graphic design principles.
